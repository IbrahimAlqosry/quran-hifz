# حِفظ وتدبُّر — تطبيق ويب لتحفيظ القرآن الكريم مع التفسير

React 18 + Bootstrap 5 (RTL) + Vite

## التشغيل

```bash
npm install
npm run dev      # تشغيل محلي على http://localhost:5173
npm run build    # نسخة للنشر في مجلد dist (تعمل على أي استضافة ثابتة)
```

## المميزات

| الصفحة | الوظيفة |
|---|---|
| **السور** | قائمة الـ114 سورة مع بحث (عربي/إنجليزي/رقم)، فلترة مكي/مدني، ونسبة الحفظ لكل سورة |
| **القراءة والتفسير** | الرسم العثماني، تفسير لكل آية أو للسورة كاملة، تلاوة آية بآية أو السورة متصلة، رقم الصفحة والجزء، علامة السجدة |
| **الحفظ** | اختيار مقطع (من/إلى)، تكرار كل آية حتى ٢٠ مرة، إعادة المقطع، ٣ أوضاع: كامل / أوائل الكلمات / إخفاء مع الإظهار بالضغط |
| **التسميع** | يعرض الآية السابقة كمفتاح، تسمّع شفهيًا أو كتابةً، مقارنة كلمة بكلمة مع نسبة الصحة، ثم تقييم ذاتي |
| **تقدّمي** | إحصائيات، مستوى التثبيت لكل سورة، تصدير/استيراد نسخة احتياطية |

**المراجعة المتباعدة:** كل آية محفوظة لها مستوى (صندوق لايتنر). «أتقنتها» ترفع المستوى وتباعد المراجعة (١ ← ٣ ← ٧ ← ١٤ ← ٣٠ ← ٦٠ ← ١٢٠ يومًا)، «تعثرت» تعيدها غدًا، «لم أحفظها» تعيدها فورًا.

## مصادر البيانات

- [AlQuran Cloud API](https://alquran.cloud/api) — مجاني وبدون مفتاح.
- النص: `quran-uthmani` للعرض، و`quran-simple-clean` للمقارنة عند التسميع الكتابي.
- التفاسير: الميسر (مجمع الملك فهد — الافتراضي)، الجلالين، البغوي، الوسيط، القرطبي.
  - تم استبعاد «تنوير المقباس» عمدًا لأن نسبته إلى ابن عباس رضي الله عنهما ضعيفة عند أهل العلم.
- التلاوات: الحصري، المنشاوي، العفاسي، عبد الباسط (مرتل).
- البيانات تُخزَّن مؤقتًا في `localStorage` لتسريع الفتح مرة ثانية.

> **تنبيه:** يُعرض التفسير كما ورد في مصدره مع ذكر اسم الكتاب تحت كل آية. يُنصح بمراجعة نص التفسير على نسخة مطبوعة معتمدة قبل استخدام التطبيق في التعليم الرسمي.

## هيكل المشروع

```
src/
  api/quran.js            طبقة الـ API + الكاش + قوائم التفاسير والقرّاء
  context/AppContext.jsx  الإعدادات + سجل الحفظ + خوارزمية المراجعة
  hooks/                  useAsync, useLocalStorage
  utils/arabic.js         توحيد النص العربي، حذف البسملة، مقارنة التسميع (LCS)
  components/             مكونات مشتركة
  pages/                  Home, SurahReader, Memorize, Test, Progress
```

## أفكار للتطوير

- Backend (مثلًا ASP.NET Core Web API + SQL Server) لحسابات المستخدمين ومزامنة الحفظ بين الأجهزة.
- لوحة للمعلّم: حلقات، طلاب، واجبات حفظ، وتقارير تسميع.
- PWA للعمل بدون إنترنت.
- التسميع الصوتي باستخدام Web Speech API (`ar-SA`).
